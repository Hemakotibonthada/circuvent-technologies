# AquaGuard - Enclosure spec

- **Type:** wall-mount ABS box, flame-retardant (UL94 V-0), light grey + cyan accent.
- **Target ingress:** IP54 (indoor/utility). Use cable glands, not open holes.
- **Approx size:** 120 x 90 x 55 mm. Wall keyholes + 4x internal PCB bosses (M3).
- **Openings:**
  - Bottom: 3 cable glands (mains, contactor, sensor/floats).
  - Front: 2 LED light-pipes (green/red), 1 button (rubber cap), buzzer grille.
- **Front graphics:** see `label.svg` (rating/spec sticker) applied to a recessed area.
- **Tooling:** injection mould (2 cavities). Provide 3D STEP from the mech vendor;
  validate PCB fit against `pcb/` board outline (80 x 60 mm) before tooling.
- **Retail carton:** see `box-dieline.svg` (E-flute, 4-color + matte lam).

Deliverables still needed from the mechanical vendor: 3D CAD (STEP), mould flow,
drop-test report, IP-rating test.
